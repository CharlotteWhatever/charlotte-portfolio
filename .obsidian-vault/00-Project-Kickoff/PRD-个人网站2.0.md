# PRD：个人网站 2.0 — Professional Journey 信息图表化

> 版本：v1.0 | 日期：2026-07-21 | 状态：开发中

## 背景与问题

1.0 版本 Professional Journey 板块使用传统时间线列表，文字密度高。招聘方需要逐条阅读才能拼凑出 Charlotte 的能力成长轨迹，无法快速扫描。

## 目标

将 Professional Journey 改造为**信息图表**，使招聘方在 10 秒内能够：
1. 看到职业跃迁路径（从哪到哪，为什么）
2. 理解能力域扩展（每个阶段新增了什么技能）
3. 感知思维成熟度（每个转折点的内在动因）

## 范围

### In Scope
- `#experience` 区域从时间线改为信息图表
- 三条可视化主线：职业流、能力雷达、思维跃迁
- 桌面版 + 移动版两个布局方案
- 中英文双语

### Out of Scope
- 其他 8 个模块保持不变
- 不改变全局配色/设计系统
- 不引入外部 JS 库
- 不改变部署方式

## 用户故事

见 `01-User-Stories/`

## 成功指标

- 招聘方扫读耗时从 ~60s 降至 ~10s（能理解职业全貌）
- 桌面/移动端均可流畅展示
- Lighthouse 性能评分不下降
- 中英文切换零 bug

## 风险

| 风险 | 缓解 |
|------|------|
| 信息密度过高导致移动端不可读 | 桌面/移动两版布局，移动端纵向叙事、减少并行信息 |
| SVG 绘制复杂度过高 | 用 CSS Flexbox + 简单内联 SVG 箭头，避免复杂图形 |
| i18n 文案量大、翻译质量不一 | 复用用户原始英文叙事，中文由 Claude 翻译后人工校对 |
