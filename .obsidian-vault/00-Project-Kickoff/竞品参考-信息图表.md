# 竞品参考：信息图表

> 收集于 2026-07-21 | 持续更新

## 参考方向

### 1. LinkedIn 职业时间线
- 垂直时间线 + 图标节点
- 优点：信息清晰、层级分明
- 缺点：适合列表不适合"能力增长"叙事

### 2. 个人网站 Infographic Resume
- 水平流程 + 能力气泡
- 参考：theinfographicon.com、visualize.me
- 优点：一屏全览、视觉冲击力强
- 缺点：移动端适配困难

### 3. SaaS 产品 Roadmap 图
- 泳道图（Swimlane）+ 里程碑节点
- 优点：适合展示并行发展（多维度能力增长）
- 缺点：对普通读者复杂度偏高

### 4. 咨询公司 Career Path 图
- 阶梯图 + 角色描述 + 关键技能标签
- 参考：McKinsey、BCG 职业发展路径
- 优点：简洁、专业感强、易理解

## 选型结论

结合以上参考，采用 **水平流程 + 能力标签云 + 转型动因标注** 的混合方案：
- 主体骨架：Roadmap 风格水平流（5节点）
- 每个节点下方：能力标签云（Neumorphism 胶囊样式）
- 节点间连接线：SVG 箭头 + 动因文案标注
- 最右侧：虚线边框 Future 节点
